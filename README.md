# edgeterm-site

Public showcase page for **edgeterm**, a crypto majors trading terminal that shows the math before and after every trade, and says so when there is no edge.

Live page: https://sacha9214.github.io/edgeterm-site/

- `index.html` is the published page: one self-contained file, no external scripts, fonts or trackers.
- `src.html` + `data.json` are its sources. `python3 build.py` inlines the data and writes `index.html`.
- Every number comes from edgeterm's own research report (generated 2026-10-26, data to 2026-10-25). The edgeterm source code itself is private.

Not investment advice.
